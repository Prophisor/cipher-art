# CaesarCipher_app

Kleines Windows Forms Projekt zur Demonstration verschiedener Verschlüsselungsverfahren (Caesar, Playfair, Matrix, Base64, MD5, AES).

## Inhalte
- GUI (WinForms) in Form1.cs
- CipherLogik in CipherLib.cs
- Tests in CaesarCipher_app.Tests (MSTest)

## Schnellstart
1. Öffne die Solution in Visual Studio (Target: .NET Framework 4.7.2).
2. Baue das Projekt.
3. Starte die Anwendung (F5).

## Features
- Caesar Cipher: Verschlüsselung/Entschlüsselung, Brute‑Force (Key=0)
- Playfair Cipher: einfache Implementierung
- Matrix Cipher: Positionen als Paare
- Base64 / MD5 / AES (Demo)
